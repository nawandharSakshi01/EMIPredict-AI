# 💰 EMIPredict AI

## Intelligent Financial Risk Assessment Platform

EMIPredict AI is a **Machine Learning-based financial risk assessment platform** that predicts whether an applicant is eligible for EMI based on their personal, employment, financial, and credit-related information.

The project uses **Machine Learning and Streamlit** to provide an interactive web application where users can enter applicant details and receive an EMI eligibility prediction.

## 🚀 Live Demo

👉 **[Try EMIPredict AI](https://emipredict-ai-znm4ssreba2kottdx2quuf.streamlit.app/)**

## 📌 Project Objectives

* Predict EMI eligibility using Machine Learning.
* Analyze an applicant's financial profile.
* Identify different financial risk categories.
* Provide prediction probabilities and confidence.
* Build an easy-to-use web application for real-time prediction.

## 🧠 Machine Learning

The project follows a complete Machine Learning workflow:

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Data Preprocessing
5. Feature Engineering
6. Model Training
7. Model Evaluation
8. Model Selection
9. Model Deployment using Streamlit

The final application uses a trained **Logistic Regression model** to predict EMI eligibility.

## 📊 Prediction Classes

The model predicts one of three categories:

* ✅ **Eligible**
* ⚠️ **High Risk**
* ❌ **Not Eligible**

The Streamlit application also displays the prediction confidence and probability for each category.
